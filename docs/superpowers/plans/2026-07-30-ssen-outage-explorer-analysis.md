# SSEN Outage Explorer, Export, and Investigation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete Phase 2 with a useful local historical-outage explorer,
deterministic filtered exports, and one reproducible public SEPD/SHEPD
investigation grounded in the accepted SSEN NaFIRS HV evidence.

**Architecture:** One resolver fixes an explicit immutable snapshot set before
a single validated `OutageFilters` contract drives event queries, counts,
summaries, breakdowns, exports, API parameters, and manifest reproduction.
Analysis reads snapshot-versioned canonical events and never re-parses source
files. GET-only versioned routes expose safe aggregates and drill-down. The
frontend renders accessible tables and distributions without adding a chart
library. Local export code fixes source contracts, canonical schema, snapshot
set, parser version, code version, filters, exclusions, and file hashes. The
published investigation and report are exact reviewed generated bytes. A
hash-verified public release asset supplies the immutable source evidence needed
for new-user reproduction.

**Tech Stack:** Python 3.11+, Pydantic 2, SQLite, FastAPI, httpx, standard-library
`csv`, `json`, `hashlib`, and `zipfile`, pytest, Ruff, Next.js 15, React 18,
strict TypeScript, Vitest, Testing Library.

## Global Constraints

- The accepted WP2.1 head and all of accepted Phase 1 must be merged before
  execution so shared database, API, page, types, and client hotspots have one
  owner at a time.
- Analyse only the verified SSEN `nafirs-hv-faults` SEPD and SHEPD resources.
- `incident_started_local` is publisher-local evidence with unknown timezone.
  Never convert it to UTC or infer elapsed incident duration.
- `average_minutes_off_supply` is an aggregate impact field, not event duration.
- The source has no event-end timestamp or event-duration field. Duration is an
  explicit unsupported evidence gap in API/UI/docs, never an alias for average
  minutes off supply.
- Missing customer-impact fields remain missing and contribute to explicit
  known/missing counts, never zero-filled totals.
- Counts describe records in the published extract, not failure rates,
  reliability performance, household histories, or causal effects.
- Every query and export preserves source dataset, resource, snapshot, parser,
  licence, attribution, and quality evidence.
- API routes are GET-only. Sync and export generation remain explicit local
  commands; the download route only packages an already defined read query.
- Generated databases, snapshots, investigation work files, and exports remain
  ignored. Only reviewed aggregate investigation artifacts enter `docs/`.
- Use `data/cache/outages/registry.sqlite3` and `data/snapshots/outages`
  explicitly in every command, API configuration, smoke test, and new-user
  workflow.
- Authenticated sources, browser sessions, portal writes, and account handling
  are out of scope.
- Immediately before every listed Git write, rerun the mandatory `ruppy7`
  identity/email/remote gate in the completion execution index and stop on any
  mismatch.

- [ ] **Step 5: Implement descriptive distributions and breakdowns**

Compute each distribution from known values only. For sorted values
`values[0:n]`, nearest-rank percentile `p` is
`values[max(ceil(p * n) - 1, 0)]`. Use full stored precision and serialise
finite floats only. Breakdowns sort chronological/numeric keys ascending and
categorical keys by descending event count then key. Missing categorical values
use key `unknown` and label `Unknown`.

Resolve reject evidence from the snapshot scope before applying event filters.

selected snapshot. For each snapshot, hash canonical sorted
`(reject_id, reject_sha256)` pairs into `reject_set_sha256`; return the ordered
per-snapshot evidence and its summed count. The count is explicitly
unfiltered by year, cause, voltage, customer impact, or quality because rejected
rows do not support those predicates. Emit a warning whenever such an event
filter is active. If a selected legacy snapshot has no verified immutable
reject materialization, return `None` and scope `unavailable`; never report
zero. An event filter returning zero events still retains the resolved
snapshots and reject evidence. Ingestion run IDs and fetch-attempt identities
are operational diagnostics only and never enter explorer, export, report, or
other hashed analytical outputs.

function Get-GitHubHttpStatus {
  param([Parameter(Mandatory)][string]$Endpoint)
  $probe = @(gh api --include --silent $Endpoint 2>&1)
  $probeExit = $LASTEXITCODE
  $statusLine = $probe |
    Where-Object { $_ -match "^HTTP/\\S+ [0-9]{3}" } |
    Select-Object -Last 1
  if (-not $statusLine) {
    throw "STOP: GitHub preflight returned no authenticated HTTP status"
  }
  $status = [int]([regex]::Match($statusLine, "[0-9]{3}").Value)
  if ($status -ge 200 -and $status -lt 300 -and $probeExit -ne 0) {
    throw "STOP: inconsistent successful GitHub preflight"
  }
  return $status
}

function Assert-ExactLightweightTag {

function Assert-ExactReleaseAsset {
  param(
    [string]$Tag,
    [string]$ExpectedCommit,
    [string]$ExpectedName,
    [long]$ExpectedSize,
    [string]$ExpectedSha256
  )
  $release = gh release view $Tag `
    --repo Ruppy7/FlexCompass `
    --json tagName,assets | ConvertFrom-Json
  if ($LASTEXITCODE -ne 0) {
    throw "STOP: existing release could not be read"
  }
  Assert-ExactLightweightTag $Tag $ExpectedCommit
  if ($release.tagName -cne $Tag) {
    throw "STOP: existing release tag name differs"
  }
  $matches = @($release.assets | Where-Object { $_.name -ceq $ExpectedName })
  if ($matches.Count -ne 1 -or $matches[0].size -ne $ExpectedSize) {
    throw "STOP: existing release asset name or size differs"
  }
  $downloadRoot = [IO.Path]::GetFullPath([IO.Path]::GetTempPath())
  $downloadDir = [IO.Path]::GetFullPath((Join-Path $downloadRoot (
    "flexcompass-release-check-" + [guid]::NewGuid().ToString("N")
  )))
  if (-not $downloadDir.StartsWith(
      $downloadRoot,
      [StringComparison]::OrdinalIgnoreCase
  )) { throw "STOP: unsafe release-check path" }
  New-Item -ItemType Directory -Path $downloadDir -ErrorAction Stop | Out-Null
  try {
    gh release download $Tag `
      --repo Ruppy7/FlexCompass `
      --pattern $ExpectedName `
      --dir $downloadDir
    if ($LASTEXITCODE -ne 0) {
      throw "STOP: existing release asset download failed"
    }
    $downloaded = Join-Path $downloadDir $ExpectedName
    $downloadedInfo = Get-Item -LiteralPath $downloaded -ErrorAction Stop

      Get-FileHash -LiteralPath $downloaded -Algorithm SHA256 -ErrorAction Stop
    ).Hash.ToLowerInvariant()
    if ($downloadedInfo.Length -ne $ExpectedSize -or
        $downloadedHash -cne $ExpectedSha256) {
      throw "STOP: existing release asset bytes differ"
    }
  } finally {
    if (Test-Path -LiteralPath $downloadDir) {
      Remove-Item -LiteralPath $downloadDir -Recurse -Force
    }
  }
}
